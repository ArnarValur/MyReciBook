Diagonal-striped placeholder for user-screenshot slots — recipe covers, heroes, import thumbnails. The stripes are the honest "your screenshot" stand-in from the hi-fi mockups; never fill these slots with stock photography.

```jsx
<StripedPlaceholder height={106} />
<StripedPlaceholder icon="photo_library" height={210} />
```

Tint derives from secondary-container, so it adapts to both themes.
