# /grill — challenge a decision before it hardens
*Emitted by Orpheus conductor-init v3.1.*

Use before anything hard to reverse: gate calls, scope changes, architecture, spend.

1. Load the relevant warm files via conductor/index.md's trigger table — grill from
   evidence, not vibes.
2. Real forks only — skip anything the hot set already answers. One topic at a time.
3. Recommend-first with reasons, then decide together with Arnar.
4. The agreement lands in a repo file the same session (workflow law 2): ADR if it
   meets the criteria, else a D-number in the track plan, else a behavioral rule
   (with explicit yes).

Sharp questions beat polite ones — agreement without evidence is worthless here.
