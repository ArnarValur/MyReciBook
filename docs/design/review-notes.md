# Hi-fi review notes — 2026-08-06 (cowork session, screens 3a–3h light+dark)

Catches to fold when the skin gets built. The hi-fi set is otherwise adopted as-is.

1. **Delete-screenshot toggle (3c): hi-fi shows ON — must DEFAULT OFF.** The lo-fi
   annotation (1a) had it right. Default-on deletes someone's original photo on
   their first save — torching the exact trust the provenance design builds — and
   Android forces a system confirm dialog per deletion anyway, so default-on buys
   nothing but risk.
2. **Favorites heart (3d, 3e): schema v1 gains optional `favorite` boolean** —
   T1 D1 amended 2026-08-06. User-owned state belongs in the user's file (delete
   the app, keep your favorites). `tags` and `notes` already exist in the schema;
   the heart was the only affordance with nowhere to live.
3. **Header pill (3d): "Synced" needs its quiet local twin** — "on this phone" —
   for the (default!) local-only users, or the pill reads as a nag to connect.
   Both states, same quiet treatment.
4. **ONE-TIME pill (3g) is magenta — the only second accent in the system.** Keep
   only if intentional as the "commerce" semantic color; otherwise fold into the
   indigo family. Flagging consistency, not taste.
