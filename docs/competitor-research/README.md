## How to read these

- Every price carries an **observation date**. Prices in this category move constantly — several of these apps run concurrent A/B price cohorts, so treat any single figure as a snapshot.
- Claims that could not be confirmed are marked `[UNVERIFIED]`. Claims resting on someone else's write-up rather than primary evidence are marked `[SECONDARY]`.
- Accusations (billing practices, review manipulation, abandonment) are labelled as accusations, not findings.
- Reddit and YouTube were unavailable to the research agents. Nothing in these files is sourced from either.

## Method note

Where possible the review agents pulled **raw review corpora** directly rather than reading the store's summary rating — 4,754 reviews for ReciMe, 2,111 for COOKmate, 1,632 for SideChef, 404 for Mob. This turned out to matter enormously: see the "the star ratings are lying" section of the synthesis.
