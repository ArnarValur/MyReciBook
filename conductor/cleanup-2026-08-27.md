## C — two bugs diagnosed, never built

Both were found while counting strings for i18n. Neither is an i18n bug, so neither
is excluded. Both re-confirmed in the code today:

1. **Serving labels ignore the units pill.** `convertUnits` is called from
   `lib/ui/recipe_detail_screen.dart` and `lib/ui/cook_mode_screen.dart` only.
   Product and diary serving labels never pass through it, so a metric user reads
   "1 cup" and "1 medium" off the starter-food table.
2. **Category is a free string on every starter food.** `Veggies` appears **65 times**
   in `lib/domain/starter_foods.dart`. One typo makes an orphan category, one rename
   is 65 edits, and it is 65 strings for the i18n sweep to hit.

The only two things on the list where code has to be written. Both small. Neither
blocks the APK in B — the APK can go first.
